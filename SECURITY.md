# Security

Report a suspected vulnerability privately to [hello@actera.dev](mailto:hello@actera.dev)
or through the repository's **Report a vulnerability** link when available.
Never post credentials, customer data, or exploit details in a public issue.

Include the affected version, the behavior you expected, and a minimal
reproduction with synthetic inputs. If an API key was exposed, replace it from
the agent's page in Actera.

Only the latest release receives fixes. There is no response-time commitment.
